# 潮汐遠航 · Tideborne

第一人稱四人海洋冒險遊戲：航海、釣魚、群島探索與海上戰鬥。

## 下載

- **第一次遊玩：** [下載 Windows 完整版](https://github.com/SKYMOPK/tideborne-updates/releases/latest/download/tideborne-windows.zip)
- **已有舊版：** [下載啟動器升級包](https://github.com/SKYMOPK/tideborne-updates/releases/latest/download/tideborne-launcher-upgrade.zip)
- [版本說明與所有下載](https://github.com/SKYMOPK/tideborne-updates/releases/latest)

完整版必須完整解壓縮，再開啟「開始遊戲.exe」。不需要安裝 Godot、Blender、Python 或 GitHub 帳號。
已有舊版時，先關閉遊戲，把升級包的兩個 EXE 覆蓋到原本遊戲資料夾（與「遊戲內容」同一層）。
之後只要使用「開始遊戲」，就會下載需要的變動封包，保留存檔與設定，不用每次重抓完整版。

下載可取消、續傳；檔案有簽章與雜湊驗證，套用失敗會嘗試還原。
更新服務無法連線時，可以遊玩目前版本。請不要直接在 ZIP 內執行。

## 四人連線

單人有獨立進度；多人由房主選擇最多四個世界，金幣、背包、魚箱、船隻與探索按世界保存。
加入朋友時使用房主世界保存的角色進度，不會帶入自己的單人裝備。舊版共用進度首次可選擇移到單人或多人世界1，原檔保留。

一人建立船隊，其他人使用房主 IP 加入。區域網路直接使用 IPv4；跨網路需要房主設定
UDP 28740 轉送，或使用彼此信任的私人虛擬區域網路。所有玩家需使用相同遊戲版本。
GitHub 只提供檔案下載，不提供遊戲房間或自動穿透服務。

WASD 移動、Shift 跑步、空白鍵跳躍，1–6 選物品、Tab 背包、E 互動、Q 放下物品。
游泳時 W 沿視線方向前進，低頭下潛、抬頭上浮；靠近船尾梯可自行攀爬回船。

此儲存庫用於發送玩家版本及更新檔，不包含開發工程與個人存檔。
